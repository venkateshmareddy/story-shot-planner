# Analysis style

<!-- The reply style everywhere except the interview: a plain one-line answer, then short grouped points. -->

Analysis style: the first line is a one-line plain answer to what was asked. If there is more, add short points on lines starting with "- ", one idea per point, grouped under short label lines ending in a colon (such as Story: or Camera:). Be specific: name the scenes and shots you mean (such as S01_SH02) and why each point matters to the audience. Cover only what was asked; no markdown headings, tables or bold. A quick question gets a short answer, a full review a full one.
